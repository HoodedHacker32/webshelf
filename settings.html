Safe search

Filters explicit results, where the search engines support it.

Asks the engines for results in this language. (They choose the country from where Webshelf’s search server is, in the US.) You can change it for one search with Tools.

Search box

Sends what you type to Webshelf’s search server, which asks Bing for suggestions (or to Wikipedia, for article titles, while the server is waking up). Also turns on “Related searches”.

Recent searches appear in the search box. They never leave this browser.

Advanced search

Adds a Dorking button to the results page: a form that writes search operators for you, with starting points such as PDF documents or government sites, and a “this site” link on each result. For research, and for finding pages directly.

Operators work in any search, with or without Easy dorking:

"sea level rise"
These words together, in this order.
-opinion
Leave out results with this word. -"a phrase" works too.
ireland OR scotland
Either word.
site:gov.ie
Only this site or domain, and its subdomains. site:edu matches every .edu address. Several, joined by OR, mean any of them.
-site:pinterest.com
Leave out this site.
filetype:pdf
Only addresses ending in .pdf (or any other extension). ext:pdf is the same.
intitle:annual
The word must be in the page title.
inurl:research
The word must be in the address.
intext:warming
The word must be in the text shown under the result.

Webshelf checks every result against the operators and tells you when none match. Bing, where most results come from, often ignores site: and filetype: when Webshelf’s server asks, so a results page with few matches links the same search on DuckDuckGo, Brave, Mojeek and Bing, which apply them.
